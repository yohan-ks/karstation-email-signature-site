3. Open your email app below and follow the steps for it.
If the logo does not show Some email apps, Gmail in particular, remove a logo that is built into a pasted signature. If that happens, click the picture icon in the signature box and add the logo file by hand (right-click the logo in the preview on the first tab and choose Save image as). The other parts of the signature are plain text and always paste fine.

If something looks wrong

The logo is missing or shows a red cross

Your email app removed the logo that is built into the signature. Open the signature box, click the picture icon (Insert image), and add the logo file by hand. You can save the file by right-clicking the logo in the preview on the first tab and choosing Save image as.

The spacing looks different after pasting

Some editors add extra space when you paste. Select everything in the signature box, delete it, then paste again. If it still looks off in Gmail, paste the signature into a new email, check it there, and send yourself a test.

The signature is missing from replies

The signature settings have two defaults: one for new messages and one for replies and forwards. Set both to your KARSTATION signature.

Roundcube shows plain text, not my signature layout

Turn on the HTML signature in Identities, and set Compose HTML messages to always under Settings, Preferences, Composing Messages (steps 3 and 5).

I changed my details and need a new signature

Come back to the first tab, edit the form, press Generate signature, copy, then replace the old signature in your email app by deleting its content and pasting the new one.
