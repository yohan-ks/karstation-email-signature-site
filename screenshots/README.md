# Screenshots for the setup guide

The guide shows a simple drawing for each step until a real screenshot exists.
Put a PNG in this folder with the exact file name below and the page uses it
automatically (no code changes). Steps without a file keep their drawing.

How to take them
- Use each app's real screen, then press Win+Shift+S (Windows) or Cmd+Shift+4 (Mac).
- Crop to the app window. About 1200 px wide is plenty. Save as PNG.
- Hide your own email address first, or blur it.
- Optional: draw a box or arrow on the button to click (Snipping Tool, Preview or Paint all can).
- Keep the file names in lowercase exactly as written.
